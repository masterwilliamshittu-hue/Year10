# Northstar GCSE Learning Hub V4

A ground-up visual redesign in a restrained black-and-silver style.

## Deploy on Render
- Create a new GitHub repository and upload all files in this folder.
- Create a Render **Web Service** connected to that repository.
- Build command: `npm install`
- Start command: `npm start`

## What's redesigned
- New sidebar navigation, dashboard, course library, lesson workspace, practice and progress pages.
- Subject cards replace the old checkbox/dropdown-heavy selection layout.
- Foundation/Higher segmented controls are used where tiering applies.
- Guided teaching comes before testing; sessions have adaptive estimated lengths.
- No OpenAI or Gemini API key is required.

## Important limitations
This is a V4 functional starter, not a verified exhaustive copy of every GCSE exam-board specification or a complete exam-question bank. Course options, English Literature set texts and RE specification must be confirmed against the student's school choices. Some lesson pages currently use modelled teaching frameworks; only the Maths factors topic has a fully worked sample lesson. Expand and verify the pre-written lesson/question bank before relying on it as complete GCSE coverage.

Profile, selected courses, completed topics and attempt counts are saved in browser localStorage on that device. This is not cloud sync or a secure multi-user account system.
